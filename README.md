# Fire Your Coworkers

Web/PWA-first office-packing comedy game.

The active public-preview implementation lives in `apps/web`. The legacy static site
and Unity prototype remain in the repository only for takeover evidence and behavioral
reference. The accepted execution order is recorded in `DISPATCHES/`.

## Local development

```powershell
pnpm install
pnpm dev
```

Then open `http://localhost:3000`.

## Verification

```powershell
pnpm typecheck
pnpm test
pnpm build
```

Visual and interaction proof belongs under `proof/24-hour-preview/`.
